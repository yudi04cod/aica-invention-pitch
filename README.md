## The pitch

> The Ceasefire Remote: a TV remote that hides itself the moment a what-to-watch argument starts and only reappears once everyone signs a tiny peace treaty on its screen.

The tiny everyday annoyance: the household argument over what to watch on TV. The ridiculous invention: a remote control that goes on strike the moment the argument starts, and only comes back once everyone has signed a tiny peace treaty on its screen — diplomacy as a remote-control feature.

## How to run

Requires Python 3.13 (standard library only, no dependencies):

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt`, validates it first (1–220 characters, exactly one sentence, single line), then reads the file back and verifies it matches the pitch exactly.
